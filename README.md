# Tréninkový parťák

Jednoduchá webová aplikace v češtině, která sestaví základní týdenní plán do posilovny podle cíle, zkušeností, času a vybavení.

## Spuštění

Otevři soubor `index.html` v prohlížeči. Aplikace nepotřebuje instalaci ani server.

> Výstup je obecný tréninkový návrh, ne zdravotní doporučení. Při bolesti nebo zdravotních omezeních se poraď s odborníkem.
